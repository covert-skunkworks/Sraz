## Sraz

A resizable remake of the 1993 Croatian DOS quiz board game *Sraz – Borba znanjem*, for Windows, Linux and macOS.

- 2–4 players on one computer, or over a LAN (the host's real network address is shown).
- Rules follow the original DOS program (see `docs/RULES.md` in the repository).
- Vector graphics that scale to any window size; English and Croatian questions.
- Nothing to install: SDL2 is built into the program.

### Downloads

| System | File |
|---|---|
| Windows 10 / 11 | `sraz-<version>-windows-x64.zip` |
| Linux x86-64 (glibc 2.35 or newer) | `sraz-<version>-linux-x64.tar.gz` |
| macOS 11 or newer, Apple Silicon and Intel | `sraz-<version>-macos-universal.zip` |

Unpack and run `sraz` (`sraz.exe` on Windows, `Sraz.app` on macOS: first start right-click › Open, it is not
notarised). Keep the `questions` folder next to the program on Windows and Linux. Details in the `README.txt` inside each package.
